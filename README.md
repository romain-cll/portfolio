# romain-caille.fr

My portfolio: projects, experience and resume. Built with TanStack Start, React and Tailwind CSS.

```bash
bun install
bun run dev    # http://localhost:3000
bun run build  # Node server in .output/, see the Dockerfile
```

The resume is `scripts/resume/resume.html`, printed to `public/resume-romain-caille.pdf` by `scripts/resume/render.sh`.
